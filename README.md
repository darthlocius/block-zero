# Block Zero

**Block Zero** is a fast-paced top-down neon pixel shooter where the player survives waves of enemies, collects upgrades, unlocks weapons, and builds powerful combat synergies.

## Features

- Fast top-down arcade combat
- Wave-based enemy progression
- Multiple weapon types
- Hunter Drone support
- Bonus selection after waves
- Synergy system
- Neon pixel-art visual style
- Browser-based gameplay

## How to Play

Survive as long as possible, destroy enemies, collect upgrades, and combine bonuses to create stronger combat builds.

## Controls

- **WASD** — Move
- **Mouse** — Aim
- **Left Mouse Button** — Shoot
- **Space / other keys** — Depends on current build and version
